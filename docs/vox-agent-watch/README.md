# VOX Agent Watch
Versión Apple Watch del sistema VOX Agent. Usa el backend original y añade un cliente watchOS transcript-first.

- `BRIEF_PRD.md`: especificación funcional y técnica, arquitectura, APIs, seguridad, datos, testing y roadmap.
- `CLAUDE_START_PROMPT.md`: prompt listo para Claude Code, con instrucciones de inspección, implementación y coordinación multiagente.

La integración Whistle para watchOS requiere una prueba en reloj físico; las cifras publicadas de Apple M4 Pro no son benchmarks de reloj.
